# E2E Scenario: multiplication-screens

Project type: desktop (tkinter, Python 3.9.6, Tk 8.5)
Spec source: docs/specs/2026-10-24-multiplication-screens.md (status: approved)

Запуск: из терминала, **`/usr/bin/python3 Math.py`** из корня репозитория, ветка
`feature/multiplication-screens`. Не `python3` из Homebrew (нет `_tkinter`) и не `python` (нет на
PATH). Запуск из терминала обязателен для TC-10 — там проверяется чистота stderr.

Это L5 — одиннадцать пунктов V3, не девять (см. исправленный `Prereq-5` в спеке и находку
`business-analyst` на цикле `/acceptance`). Решение пользователя 2026-10-28: AC-1 закрывается
**ослабленной формой** — машинный замер `root` 992×694 ≤ 1024×768 принят как достаточный критерий
для личного тренажёра, реальной смены системного разрешения экрана не требуется.

## TC-1 (AC-1) — девятая кнопка видна и нажимаема
1. Открыть главный дашборд.
2. Убедиться, что четвёртый столбец содержит девять кнопок `Умножение на 1` … `Умножение на 9` по
   порядку номеров, без визуальных артефактов.
3. **Ослаблено по решению пользователя:** реальное изменение системного разрешения на 1024×768 не
   требуется; достаточно визуально убедиться, что кнопка `Умножение на 9` не обрезана и доступна
   для клика на текущем экране.

## TC-2 (AC-3) — независимые окна
1. Кликнуть `Умножение на 3` → открывается окно `500x700`, фон `lightblue`, заголовок «Умножение
   на 3».
2. Открыть ещё `Умножение на 7`, не закрывая первое.
3. Ответить в одном окне — счётчик другого не меняется. Главное окно остаётся рабочим.

## TC-3 (AC-4) — визуальное сличение с каноном
1. Сравнить состав и оформление нового экрана с экраном «Минус: 1-значное из 2-значного»: шрифты,
   цвета, расположение кнопки «назад», вопроса, вариантов, результата, статистики, кнопки
   «Сбросить».

## TC-4 (AC-5) — формат вопроса
1. На любом экране «Умножение на N» пройти 30 вопросов.
2. Убедиться, что первый множитель всегда N, второй — в диапазоне 2..9, формат `N × b = ?` со
   знаком `×`.

## TC-5 (AC-6, вторичное подтверждение) — без повтора второго множителя
1. На том же прогоне 30 вопросов убедиться, что второй множитель никогда не повторяется в двух
   вопросах подряд.

## TC-6 (AC-9) — пять верных ответов подряд
1. Пять раз выбрать правильный вариант.
2. Каждый раз: все шесть кнопок блокируются сразу, результат — «Correct! Well done!» зелёным,
   пауза ~2 секунды, счётчик «Correct» растёт на 1, приходит новый вопрос, кнопки снова активны.

## TC-7 (AC-10) — пять неверных ответов подряд
1. Пять раз выбрать неправильный вариант.
2. Каждый раз: блокировка, результат — «Incorrect. The correct answer is: …» красным, пауза,
   счётчик «Incorrect» растёт на 1, новый вопрос.

## TC-8 (AC-11) — клики во время паузы игнорируются
1. Ответить (верно или неверно).
2. Пока виден результат, пощёлкать по другим кнопкам — ничего не меняется: ни счётчик, ни текст
   результата, ни вопрос.

## TC-9 (AC-12) — «Сбросить»
1. **Вне паузы:** набрать несколько верных/неверных ответов, нажать «Сбросить» — оба счётчика
   показывают 0, текущий вопрос и варианты не меняются.
2. **Во время паузы:** ответить, сразу нажать «Сбросить», пока на экране виден текст результата —
   счёт сразу показывает `0 : 0`, текст результата **не исчезает раньше времени** (остаётся до
   конца обычной паузы), следующий вопрос приходит в обычном темпе, счёт по-прежнему `0 : 0` (ход
   не засчитан).

## TC-10 (AC-13) — закрытие экрана
1. Ответить, сразу нажать «Back» пока виден результат (во время паузы) — окно закрывается, в
   терминале никакого traceback/Tcl-ошибки, другие окна и главное окно продолжают работать.
2. Отдельно: ответить, закрыть то же окно системным крестиком (✕) во время паузы — тот же чистый
   результат.
3. Открыть тот же экран `Умножение на N` повторно — счётчики начинаются с нуля.

## TC-11 (AC-14) — регрессия существующих экранов
1. Спот-прогон «Addition (0-20)» на 3 вопроса — работает как раньше.
2. Спот-прогон «Минус: 1-значное из 2-значного» на 3 вопроса — **вопрос вида `3 - 47 = ?` с
   отрицательным ответом — известный дефект вне scope этой задачи (`Math.py:1359-1373`), принимать
   его за регрессию нельзя.**
